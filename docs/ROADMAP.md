# MindWeb · 我的心情地圖 — 產品構想與製作地圖

> 一個安裝在 iPhone 主畫面的 Web App（PWA），幫你記住**每一次諮商前後的心情**，
> 讓你看見自己一路走來的變化，也讓下一次諮商更有方向。

---

## 1. 核心想法（把想法說完整）

### 1.1 要解決的問題
- 諮商結束後的感受很強烈，但幾天後就模糊了，下次見面時很難說清楚「這週怎麼了」。
- 諮商師說過的關鍵一句話、自己突然想通的事，常常記不住。
- 很難看到長期變化：我真的有比較好嗎？哪些主題反覆出現？

### 1.2 一句話定位
**「每次諮商的心情日記 + 自己的情緒地圖」**：諮商前記一下、諮商後記一下，
App 幫你把一次次的紀錄串成一張看得見的地圖。

### 1.3 使用者旅程（一次諮商的完整循環）

```
諮商前 (5 分鐘)            諮商後 (10 分鐘)             之間的日子 (可選)          下次諮商前
┌──────────────┐        ┌──────────────────┐       ┌──────────────┐       ┌──────────────────┐
│ 現在心情如何？ │  ──▶  │ 結束後的心情       │  ──▶ │ 快速心情打卡   │  ──▶ │ 回顧上次 + 這週   │
│ 想談什麼？     │        │ 談了什麼、關鍵一句 │       │ 想到的事先記下 │       │ 整理「想帶去說的」 │
└──────────────┘        │ 回家功課/練習       │       └──────────────┘       └──────────────────┘
                        └──────────────────┘
```

### 1.4 一筆「諮商紀錄」包含什麼
| 欄位 | 說明 | MVP |
|---|---|---|
| 日期 / 第幾次 | 自動帶入，可修改 | ✅ |
| 諮商前心情 | 1–10 分 + 情緒標籤（焦慮、平靜、難過、期待…） | ✅ |
| 想談的事 | 短文字 | ✅ |
| 諮商後心情 | 1–10 分 + 情緒標籤 | ✅ |
| 談了什麼 | 主題標籤（家庭、工作、關係、自我…）+ 自由書寫 | ✅ |
| 印象最深的一句話 | 諮商師說的、或自己說出口的 | ✅ |
| 身體感受 | 胸口緊、放鬆、疲累…（可選） | ⏳ |
| 回家功課 / 想練習的事 | 可勾選完成 | ⏳ |
| 下次想帶去說的事 | 之間的日子隨時新增 | ⏳ |
| 語音備忘 / 照片 | 不想打字時用 | 🔮 |

✅ 第一版就做　⏳ 第二版　🔮 之後再說

### 1.5 「地圖」要長什麼樣子（產品的靈魂）
1. **時間軸地圖**：每次諮商是一個點，顏色＝心情，諮商前→後畫成一條小箭頭，一眼看出「這次談完有沒有比較好」。
2. **心情曲線**：諮商前 / 後兩條線，看長期趨勢。
3. **主題星圖**：常談的主題變大顆，相關主題連成線（例如「家庭」常和「自我價值」一起出現）。
4. **金句牆**：所有「印象最深的一句話」集合起來，難過時可以翻。

### 1.6 設計原則
- **溫柔、不評價**：不用「好/壞」字眼，不推送「你連續 3 天沒記錄！」這種壓力。
- **10 秒也能記**：最低限度只要拉一下心情分數就能存。
- **隱私第一**：資料預設只存在自己的手機裡，不需要註冊帳號。
- **安全網**：設定頁與低分紀錄時，溫和地顯示求助資源（台灣：安心專線 1925、生命線 1995、張老師 1980）。

## 2. 技術選型（iOS Web App）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 形式 | **PWA**（加入主畫面） | 不用上架 App Store，iPhone 上全螢幕、有圖示、可離線 |
| 前端框架 | **Vite + React + TypeScript** | 生態系完整、好找教學 |
| 樣式 | Tailwind CSS | 快速做出柔和、手機優先的介面 |
| 本機資料庫 | **IndexedDB（用 Dexie.js）** | 資料留在手機、離線可用 |
| 圖表 | Recharts 或 D3 | 心情曲線、主題星圖 |
| 離線 / 安裝 | vite-plugin-pwa（Service Worker + manifest） | iOS「加入主畫面」所需 |
| 上鎖 | App 內 PIN 碼；進階可用 Passkey（WebAuthn，會觸發 Face ID） | Web App 無法直接呼叫 Face ID API |
| 部署 | GitHub Pages / Vercel / Netlify（免費） | 推到 GitHub 自動上線 |
| 雲端同步（之後） | Supabase 或 Firebase + **端對端加密** | 換手機不怕資料消失 |

### iOS PWA 要注意的事
- 必須用 Safari「分享 → 加入主畫面」才算安裝；需要做一個「如何安裝」引導頁。
- iOS 16.4+ 已安裝的 PWA 才支援推播通知（可做「諮商後記得記錄」提醒）。
- Safari 可能在長時間未使用時清除網站資料 → 要提供**匯出/備份**功能，並呼叫 `navigator.storage.persist()`。
- 處理瀏海與底部 Home 條：使用 `viewport-fit=cover` 與 `env(safe-area-inset-*)`。

## 3. 資料結構（草稿）

```ts
interface Session {
  id: string;
  number: number;            // 第幾次諮商
  date: string;              // ISO 日期
  before?: MoodCheck;
  after?: MoodCheck;
  wantToTalk?: string;       // 諮商前想談的
  topics: string[];          // 主題標籤
  notes?: string;            // 談了什麼
  keyQuote?: string;         // 印象最深的一句話
  homework?: Task[];
  createdAt: string;
  updatedAt: string;
}

interface MoodCheck {
  score: number;             // 1–10
  emotions: string[];        // 情緒標籤
  bodyFeelings?: string[];
  note?: string;
}

interface Task { id: string; text: string; done: boolean; }

interface BringUpItem {      // 下次想帶去說的事
  id: string;
  text: string;
  createdAt: string;
  resolvedInSessionId?: string;
}
```

## 5. 待你決定的問題
1. **只給自己用，還是之後想給其他人用？** → 影響要不要做帳號、雲端、隱私政策。
2. **想不想讓諮商師看到？** → 影響匯出/分享功能的優先順序。
3. **記錄偏好**：喜歡打字、勾選，還是語音？
4. **每次諮商之間**也想記錄心情嗎，還是只記諮商當天？
5. **外觀感覺**：溫暖手帳風、極簡、還是插畫可愛風？

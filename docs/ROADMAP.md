# MindWeb · 我的心情地圖 — 產品構想與製作地圖

> 一個安裝在 iPhone 主畫面的 Web App（PWA），幫你記住**每一次諮商前後的心情**，
> 讓你看見自己一路走來的變化，也讓下一次諮商更有方向。

---

## 1. 核心想法（把想法說完整）

### 1.1 要解決的問題
- 諮商結束後的感受很強烈，但幾天後就模糊了，下次見面時很難說清楚「這週怎麼了」。
- 諮商師說過的關鍵一句話、自己突然想通的事，常常記不住。
- 很難看到長期變化：我真的有比較好嗎？哪些主題反覆出現？

### 1.2 一句話定位
**「每次諮商的心情日記 + 自己的情緒地圖」**：諮商前記一下、諮商後記一下，
App 幫你把一次次的紀錄串成一張看得見的地圖。

### 1.3 使用者旅程（一次諮商的完整循環）

```
諮商前 (5 分鐘)            諮商後 (10 分鐘)             之間的日子 (可選)          下次諮商前
┌──────────────┐        ┌──────────────────┐       ┌──────────────┐       ┌──────────────────┐
│ 現在心情如何？ │  ──▶  │ 結束後的心情       │  ──▶ │ 快速心情打卡   │  ──▶ │ 回顧上次 + 這週   │
│ 想談什麼？     │        │ 談了什麼、關鍵一句 │       │ 想到的事先記下 │       │ 整理「想帶去說的」 │
└──────────────┘        │ 回家功課/練習       │       └──────────────┘       └──────────────────┘
                        └──────────────────┘
```

### 1.4 一筆「諮商紀錄」包含什麼
| 欄位 | 說明 | MVP |
|---|---|---|
| 日期 / 第幾次 | 自動帶入，可修改 | ✅ |
| 諮商前心情 | 1–10 分 + 情緒標籤（焦慮、平靜、難過、期待…） | ✅ |
| 想談的事 | 短文字 | ✅ |
| 諮商後心情 | 1–10 分 + 情緒標籤 | ✅ |
| 談了什麼 | 主題標籤（家庭、工作、關係、自我…）+ 自由書寫 | ✅ |
| 印象最深的一句話 | 諮商師說的、或自己說出口的 | ✅ |
| 身體感受 | 胸口緊、放鬆、疲累…（可選） | ⏳ |
| 回家功課 / 想練習的事 | 可勾選完成 | ⏳ |
| 下次想帶去說的事 | 之間的日子隨時新增 | ⏳ |
| 語音備忘 / 照片 | 不想打字時用 | 🔮 |

✅ 第一版就做　⏳ 第二版　🔮 之後再說

### 1.5 「地圖」要長什麼樣子（產品的靈魂）
1. **時間軸地圖**：每次諮商是一個點，顏色＝心情，諮商前→後畫成一條小箭頭，一眼看出「這次談完有沒有比較好」。
2. **心情曲線**：諮商前 / 後兩條線，看長期趨勢。
3. **主題星圖**：常談的主題變大顆，相關主題連成線（例如「家庭」常和「自我價值」一起出現）。
4. **金句牆**：所有「印象最深的一句話」集合起來，難過時可以翻。

### 1.6 設計原則
- **溫柔、不評價**：不用「好/壞」字眼，不推送「你連續 3 天沒記錄！」這種壓力。
- **10 秒也能記**：最低限度只要拉一下心情分數就能存。
- **隱私第一**：資料預設只存在自己的手機裡，不需要註冊帳號。
- **安全網**：設定頁與低分紀錄時，溫和地顯示求助資源（台灣：安心專線 1925、生命線 1995、張老師 1980）。

## 2. 技術選型（iOS Web App）

| 項目 | 選擇 | 理由 |
|---|---|---|
| 形式 | **PWA**（加入主畫面） | 不用上架 App Store，iPhone 上全螢幕、有圖示、可離線 |
| 前端框架 | **Vite + React + TypeScript** | 生態系完整、好找教學 |
| 樣式 | Tailwind CSS | 快速做出柔和、手機優先的介面 |
| 本機資料庫 | **IndexedDB（用 Dexie.js）** | 資料留在手機、離線可用 |
| 圖表 | Recharts 或 D3 | 心情曲線、主題星圖 |
| 離線 / 安裝 | vite-plugin-pwa（Service Worker + manifest） | iOS「加入主畫面」所需 |
| 上鎖 | App 內 PIN 碼；進階可用 Passkey（WebAuthn，會觸發 Face ID） | Web App 無法直接呼叫 Face ID API |
| 部署 | GitHub Pages / Vercel / Netlify（免費） | 推到 GitHub 自動上線 |
| 雲端同步（之後） | Supabase 或 Firebase + **端對端加密** | 換手機不怕資料消失 |

### iOS PWA 要注意的事
- 必須用 Safari「分享 → 加入主畫面」才算安裝；需要做一個「如何安裝」引導頁。
- iOS 16.4+ 已安裝的 PWA 才支援推播通知（可做「諮商後記得記錄」提醒）。
- Safari 可能在長時間未使用時清除網站資料 → 要提供**匯出/備份**功能，並呼叫 `navigator.storage.persist()`。
- 處理瀏海與底部 Home 條：使用 `viewport-fit=cover` 與 `env(safe-area-inset-*)`。

## 3. 資料結構（草稿）

```ts
interface Session {
  id: string;
  number: number;            // 第幾次諮商
  date: string;              // ISO 日期
  before?: MoodCheck;
  after?: MoodCheck;
  wantToTalk?: string;       // 諮商前想談的
  topics: string[];          // 主題標籤
  notes?: string;            // 談了什麼
  keyQuote?: string;         // 印象最深的一句話
  homework?: Task[];
  createdAt: string;
  updatedAt: string;
}

interface MoodCheck {
  score: number;             // 1–10
  emotions: string[];        // 情緒標籤
  bodyFeelings?: string[];
  note?: string;
}

interface Task { id: string; text: string; done: boolean; }

interface BringUpItem {      // 下次想帶去說的事
  id: string;
  text: string;
  createdAt: string;
  resolvedInSessionId?: string;
}
```

## 5. 已確定的方向（2026-10）

| 問題 | 決定 | 對產品的影響 |
|---|---|---|
| 給誰用 | **先給自己用** | 不做帳號、不做雲端；資料只在手機，備份用匯出檔 |
| 給諮商師看 | **暫時不用** | 匯出 PDF 移到最後，不影響 MVP |
| 記錄方式 | **打字，但希望不要有負擔** | 見 5.1「低負擔輸入」 |
| 記錄範圍 | **只記諮商當天**，之間的事「或許」 | 「之間的日子」做成一個小小的可選入口，不是主功能 |
| 外觀 | **藍天、白雲、草地、飛機，溫暖的手繪動畫感** | 見 5.2「視覺方向」 |

### 5.1 低負擔輸入：打不完整也沒關係
- **先點、再寫**：每一題都先有可以直接點的選項（情緒、主題），文字永遠是選填。
- **一個詞也算數**：輸入框提示寫「一個詞、半句話都可以」，不設字數，不顯示空白欄位的警告。
- **句子開頭幫你起頭**：點一下就帶入「今天我最想說的是…」「我發現我其實…」「讓我卡住的是…」，接著寫就好。
- **用 iPhone 鍵盤的麥克風聽寫**：不用另外開發語音功能，在引導頁教一次就好。
- **可以晚點再補**：諮商後先存心情分數，App 會留一朵「還沒寫完的雲」，想補的時候再點開，不催促。
- **心情用天氣表示**：不一定要想分數，可以選 ☀️ 晴朗、⛅ 有點雲、☁️ 陰天、🌧️ 下雨、⛈️ 雷雨（背後仍對應 1–10 分，方便畫曲線）。

### 5.2 視覺方向：繪本風（第二版樣稿後修正）
- 第一版「動畫電影感」（漸層、光暈、陰影）太像 AI 生成，不採用。
- 改成**繪本裡那種有點假的藍天**：平塗色塊、蠟筆般微微抖動的外框、紙張顆粒，沒有漸層和光暈。
- **首頁極簡**：只有日期、一句「你已經走了 N 次」、一個「記下今天」按鈕。心情複雜時打開也不會有壓力。
- **地圖 = 一條橫向小路**：側面看過去的繪本風景，小路從左（過去）往右（前方）延伸，可以左右滑。每次諮商是路上的一個圓點，顏色代表諮商後的天氣；一個大大的小人站在最新的圓點上，離畫面很近。
- **細節**：遠山、樹、起點的小房子、木頭圍籬、小路上的腳印、草地上的小花、蝴蝶、小鳥；天空固定不動，只有地面會滑。
- 點圓點才出現小對話框（日期、天氣、這次的歌），其餘資訊收在「全部紀錄」裡。
- 夜間模式：平塗的深藍夜空與星星。
- 字體：粉圓體（Huninn）。

### 5.3 音樂：「這次的歌」
- 不使用 AI 音樂，也不在 App 內存放音樂檔（避免版權問題）。
- **使用 Spotify**。第一版：在 App 裡登入一次 Spotify（PKCE 授權，不需要伺服器），之後用歌名搜尋、點選；紀錄裡顯示 Spotify 官方嵌入播放器，旁邊放「在 Spotify 打開」。
  - 需要申請免費的 Spotify 開發者應用程式（開發模式給自己用即可）。
  - 嵌入播放器在 iPhone 主畫面 Web App 中能否播完整首歌，需實測；最差情況是試聽片段＋一鍵跳到 Spotify。
- **之後：在 App 裡直接播放（綁自己的帳號）**，三條路：
  | 服務 | 能否在 iPhone 的 Web App 裡播 | 條件 |
  |---|---|---|
  | Apple Music（MusicKit JS） | 可以，登入後播完整歌曲 | 需要 Apple Music 訂閱；開發者需 Apple Developer Program（每年 US$99）；實際效果要在 iPhone 上測試 |
  | Spotify | Web Playback SDK **不支援手機瀏覽器**；改用「遙控」方式：App 裡選歌、按播放，由手機上的 Spotify App 播出 | 需要 Spotify Premium；用開發模式給自己用即可 |
  | YouTube（官方嵌入播放器） | 可以，免帳號 | 會有廣告；螢幕關掉或切走時通常會停 |

### 5.4 首頁的話：每次打開都有一點不一樣
- 罐頭安慰句太像 AI，不用。
- **以事實為主，語氣帶一點溫度**：從自己的紀錄算出來，例如「10/15 之後，已經走了 5 天。」「上次走完的那天，是有點雲。」「再兩天就是週四，又要去說說話了。」「這幾天在路上，記下了 2 件事。」
- **補充：自己記下的金句**：偶爾換成以前記過的「印象最深的一句話」。
- 同一天內不換句子；不催促、不評價。

### 5.5 圓點的設計：實心點與虛線點（取代「諮商前／後」）
- **實心點 = 諮商當天**：一次只記一份，不分前後。**一題一個畫面**，只有天氣必填，其他都能跳過：
  1. 天氣（晴朗／有點雲／陰天／下雨／雷雨），不另外分心情強弱
  2. 心情（可複選）：平靜、輕鬆、感謝、有希望、疲累、焦慮、難過、生氣、委屈、困惑、空空的、說不出來
  3. 談了什麼（可複選、可新增）：家庭、感情、朋友、工作／學業、自己、身體／睡眠、過去的事
  4. 印象最深的一句話（不標記是誰說的）
  5. 筆記（不提供句子開頭）
  6. 這次的歌：在 App 裡直接搜尋 Spotify 選歌（不用貼連結）
  - 不放照片。
- **虛線點 = 兩次諮商之間的路上**：小人站在最新的實心點上，前方到下一個實心點之間有一個虛線點。點它就能隨手記下這段時間發生的事、想到的話（可以記很多則，每則一句也可以）。
- 每則：一段文字（可省略）＋當下天氣（可選）＋「想帶去說」星星；只點天氣也算一則。
- 下一次諮商當天，把有星星的拿出來看，就是「想帶去說的事」；不需要勾選「說到了」。
- 諮商後，虛線點留在兩個實心點之間；沒記任何東西的虛線點就不顯示。
